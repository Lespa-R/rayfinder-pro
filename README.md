# RayFinder Pro

RayRadar

Ce que fait l’app (MVP simple) :

Détecte les Ray-Ban Meta / smart glasses à proximité via Bluetooth (technique déjà prouvée).

Alerte sonore + visuelle discrète.

Mode « radar » en temps réel (carte ou liste des détections autour de toi).

Bouton « Share the sighting »

Mode « Safe Zone » : alerte les amis autour de toi.

Stats communautaires (combien de détections dans ta ville aujourd’hui).
